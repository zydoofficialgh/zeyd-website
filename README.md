# ZYDO — موقع شخصي متعدد اللغات

موقع شخصي متجاوب بتصميم داكن أنيق، يدعم العربية والإنجليزية البريطانية والفرنسية البلجيكية، ويعمل كصفحة ثابتة دون قاعدة بيانات.

## الملفات
- `index.html` — بنية الموقع.
- `styles.css` — التصميم المتجاوب.
- `app.js` — عرض البيانات، تبديل اللغات، معرض الصور، ومساعد الأسئلة التجريبي.
- `config.js` — **الملف الذي ستعدّل فيه معلوماتك عادةً**.

## تعديل الموقع بأبسط طريقة
1. افتح `config.js` بمحرر نصوص مثل Visual Studio Code أو محرر نصوص الهاتف.
2. عدّل الاسم، النبذة، الحالة، الاهتمامات، محطات الدراسة، النصائح، الصور والروابط.
3. ارفع الملفات المعدّلة إلى الاستضافة نفسها.
4. لا تضع معلومات حساسة في هذا الملف؛ كل ما فيه متاح للزوار ويمكن قراءته من المتصفح.

### إضافة صورة شخصية أو صور للمعرض
أنشئ مجلداً اسمه `assets`، وضع الصور فيه. مثال:
- `assets/profile.jpg`
- `assets/trip.jpg`

ثم في `config.js`:
```js
profileImage: "assets/profile.jpg",
```
وفي عنصر من `gallery` اجعل `image: "assets/trip.jpg"`.

### إضافة روابط التواصل
في `contacts`، اكتب الرابط الكامل. مثال:
```js
{ label: "Instagram", url: "https://www.instagram.com/YOUR_HANDLE/", icon: "◎" }
```
إذا تركت `url` فارغاً فلن يظهر الرابط للزوار.

### السيرة الذاتية والشهادات
يمكنك نشر ملف PDF عام داخل `assets` ثم وضع مساره في `cvUrl`. لا تنشر شهادات تحتوي على رقم وطني أو رقم طالب أو توقيع أو معلومات غير ضرورية. يمكن إضافة قسم للشهادات داخل `timeline` أو إضافة حقل جديد للواجهة لاحقاً.

## اللغات
اللغة الافتراضية عربية. يستخدم زر أعلى الصفحة:
- العربية
- English (UK)
- Français (Belgique)

النصوص الظاهرة للزوار موجودة في قاموس `dict` داخل `app.js`، والمعلومات الشخصية متعددة اللغات في `config.js`. عند إضافة محتوى جديد، أضف صياغته إلى `ar`, `en`, و`fr` حتى تظهر الترجمة المناسبة.

## مساعد المحادثة: توضيح مهم
النسخة المرفقة تحتوي على **مساعد محلي تجريبي** يبحث في المعلومات العامة المنشورة في الموقع. عند تحديث `config.js`، يقرأ النسخة الجديدة من المعلومات تلقائياً بعد نشر التحديث. لكنه ليس نموذج ذكاء اصطناعي توليدياً، وقد لا يفهم الأسئلة المركبة أو المرادفات بدقة.

للحصول على Chatbot حقيقي يستخدم نموذج ذكاء اصطناعي:
- أضف backend/serverless function (مثلاً Vercel Functions).
- خزّن مفتاح API في متغيرات البيئة على الخادم فقط، وليس في `config.js` أو `app.js`.
- أرسل إلى النموذج فقط المعلومات العامة التي تختار نشرها، مع تعليمات صريحة بعدم اختلاق معلومات غير موجودة.
- أضف حدود استخدام وحماية من إساءة الاستخدام. قد تكون هناك تكلفة API حسب المزوّد والاستخدام.

## النشر المجاني
يمكن نشر الملفات الثابتة على GitHub Pages أو Vercel أو Netlify. ارفع المجلد إلى مستودع أو مشروع الاستضافة واتبع خطوات النشر في المنصة المختارة. يجب أن تكون أسماء الملفات والمسارات مطابقة لحالة الأحرف.

## الأداء والخصوصية
- لا توجد قاعدة بيانات أو تتبّع أو ملفات تعريف ارتباط إعلانية في هذا القالب.
- اختيار اللغة يُحفظ محلياً في متصفح الزائر.
- سرعة التحميل الفعلية تعتمد على الشبكة والاستضافة والصور؛ لا يمكن ضمان تحميل أقل من ثانية في كل الظروف.
- لا تنشر حالتك الصحية، موقعك الدقيق، تفاصيل العلاقات، أرقام الوثائق، كلمات المرور أو معلومات أشخاص آخرين. أنشئ أقساماً خاصة فقط إذا كانت محمية فعلياً بتسجيل دخول وخادم؛ إخفاء القسم من الواجهة لا يجعل البيانات سرية.

## ملاحظة عن التحكم
`config.js` طريقة سهلة لتحديث المحتوى، لكنها ليست لوحة إدارة عبر المتصفح: التعديلات تحتاج إلى رفع الملفات مجدداً. لوحة إدارة حقيقية تحفظ التعديلات تحتاج إلى خدمة مصادقة وتخزين أو CMS.
